# Настройка оформления виджетов

Интерактивная демка виджета «Текст». Слева находится виджет на холсте, справа — окно настроек. Изменения отображаются на холсте сразу. Кнопка сброса в шапке возвращает исходные настройки.

- «Область ввода» содержит независимые настройки оформления для трёх состояний.
- «Метка» и «Подсказка» добавляются из подвала или меню «Добавить».
- «Размер» позволяет менять габариты и отступы.
- Окно выбора цвета общее для текста, метки, границ, фона и тени. «Мои» и история доступны до обновления страницы.

## Запуск

Откройте `index.html` в браузере или раздайте папку через статический HTTP-сервер. Демка состоит из HTML, CSS и JavaScript. Сборка, установка пакетов и серверная часть не требуются. Пипетка доступна в браузерах с поддержкой EyeDropper API.

## Публикация на GitHub Pages

Поместите содержимое этой папки в корень отдельного репозитория. В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`. Файл `.nojekyll` позволяет публиковать статические файлы напрямую. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Структура

- `index.html`, `app.js` и `styles.css` — холст и редактор виджета.
- `color-dialog.js` связывает редактор с отдельной страницей `color-window.html`.
- `color-window/` содержит компонент выбора цвета из демки фона и его интеграцию.
- `assets/` содержит иконки и локальные ресурсы демки.
